# Портфоліо Павла

Статичний сайт: `index.html` + папка `img/`. Без збірки.

## Як додати роботу
1. Покладіть картинки у `img/` (краще .webp, ширина до 1800 px).
2. У `index.html` скопіюйте блок `<article class="case">…</article>` і замініть тексти та шляхи до картинок.
3. Додайте рядок у список `<ol class="index">` на початку сторінки.

## Публікація
Cloudflare Pages або GitHub Pages: корінь репозиторію — це сайт (папка збірки порожня, build-команди немає).
